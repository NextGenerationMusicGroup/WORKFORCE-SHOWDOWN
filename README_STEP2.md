# Workforce Showdown — Step 2

## What's new
- Detailed articulated procedural human fighters with face, eyes, brows, nose, ears, hair, hands/fingers, layered clothing, work badge/lapel pin, tailored trousers, and footwear.
- Explicit idle, walk, punch, kick, hit-reaction, and knockout animation states.
- Employee and executive outfit variants preserve the existing roster and boardroom arena.
- Existing controls, health bars, timer, AI opponent, and round restart remain.

## Run
Open `Workforce_Showdown_3D_Step2.html` in a modern browser with internet access. Three.js is imported from jsDelivr. If your browser blocks ES modules from local files, serve the folder with any static HTTP server, e.g. `python -m http.server 8000`, then open `http://localhost:8000/Workforce_Showdown_3D_Step2.html`.

## Asset status
This step uses procedural meshes rather than a downloaded rigged/photogrammetry asset. That keeps the prototype self-contained and editable. For production-level realism, the next asset pass should add licensed, artist-authored rigged GLB characters and retargeted motion-capture clips.
