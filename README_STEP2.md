# Workforce Showdown — Enhanced Graphics Edition

This package is a separate enhanced build. The original working Step 2 HTML is preserved as `Workforce_Showdown_3D_Step2_ORIGINAL.html`. The active `Workforce_Showdown_3D_Step2.html` uses the same working combat logic and procedural fighters, with upgraded lighting, shadows, and arena details.

## Run it

Open `Workforce_Showdown_3D_Step2.html` from this folder using your existing local web server. The page uses Three.js from a public CDN, so an internet connection is required. The separate `server.js` / `package.json` are preserved unchanged.

Note: the fighters are detailed procedural models, not photorealistic scanned characters.
