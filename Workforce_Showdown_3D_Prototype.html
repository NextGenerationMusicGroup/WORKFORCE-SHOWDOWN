This is a standalone 3D proof of concept. It uses procedural 3D fighters and a boardroom arena so we can validate the camera, movement, attack timing, and health UI before adding detailed character models.

Round ready — move in and test a strike.

Controls

Keyboard: A/D or ←/→ move · W/↑ jump · J punch · K kick · hold L to block · I special. Click/tap the buttons for touch controls. The opponent is a simple training dummy for this first milestone.

Prototype note: this is the first implementation step, not the finished realistic 3D game. Three.js loads from a public CDN, so internet access is needed. The existing online server and tournament files are unchanged.
